JEDI reference

Model-serving glossary

Bundle

The deployable directory containing the trained pipelines, feature schema, golden input/output, and manifest.

Manifest

The bundle's identity card and tamper-evident inventory. It names every required file and stores its SHA-256 checksum plus contract and runtime versions.

Runtime load

Reading the bundle from the deployed function, verifying it, loading the pipelines into memory, and running the golden prediction.

Registration

Writing immutable bundle metadata into PostgreSQL as a candidate ModelVersion. Registration does not train or upload the model.

Deployment check

Proof that the loaded runtime has the same artifact hash and request, response, and feature contracts as the selected registry row.

Activation

Choosing which already-registered, successfully checked version future ranking runs will pin.
