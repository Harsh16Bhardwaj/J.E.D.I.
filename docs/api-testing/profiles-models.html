Profiles and model metadata

Create immutable versions, then explicitly activate one profile and one model. All routes require the user cookie.

POST/api/profiles

Create an immutable resume/preference profile.

http://localhost:8000/api/profiles
{
  "resumeText": "Python backend engineer with FastAPI and PostgreSQL experience.",
  "preferredTitles": ["Backend Engineer", "ML Engineer"],
  "preferredLocations": ["Remote", "Bengaluru"],
  "preferredSkills": ["Python", "FastAPI", "PostgreSQL"],
  "experienceMinYears": 1,
  "experienceMaxYears": 4,
  "salaryMin": 800000,
  "salaryMax": 2500000,
  "salaryCurrency": "INR"
}
Expect
201, active:false, contentHash and ID. Copy the ID.
Replay
Send the identical normalized content and expect 200, same ID and replayed:true.
Failure
Set minimum experience above maximum and expect 422.

GET/api/profiles

List profile summaries newest first.

http://localhost:8000/api/profiles
Expect
200 array with ID, active flag and resume preview.
Failure
Without the login cookie expect 401.

GET/api/profiles/active

Read the profile normalization will use.

http://localhost:8000/api/profiles/active
Expect
200 after activation.
Failure
Before any activation expect 404 NOT_FOUND.

GET/api/profiles/PASTE_PROFILE_ID_HERE

Read a complete immutable profile.

http://localhost:8000/api/profiles/PASTE_PROFILE_ID_HERE
Expect
200 including resumeText, preferences and contentHash.
Failure
Use missing as the ID and expect 404.

POST/api/profiles/PASTE_PROFILE_ID_HERE/activate

Atomically make this the only active profile.

http://localhost:8000/api/profiles/PASTE_PROFILE_ID_HERE/activate
Body
None
Expect
200 with active:true.
Check
List profiles and verify exactly one active item.
Failure
Activate an unknown ID and expect 404.

POST/api/models

Register immutable model metadata; no artifact is loaded.

http://localhost:8000/api/models
{
  "name": "jedi-ranking-postman-v1",
  "artifactManifest": {
    "bundle": "ML/models/jedi-ranking-postman-v1",
    "ranker": "stacked_drop5"
  },
  "featureSchemaVersion": "prepared-job-v1",
  "metrics": {
    "precisionAt25": 0.968,
    "ndcgAt25": 0.9752
  }
}
Expect
201, ID, contentHash and active:false. Copy the ID.
Replay
Identical metadata returns 200 and replayed:true.
Failure
Reuse the name with different metadata and expect 409 CONFLICT.

GET/api/models

List all registered model versions.

http://localhost:8000/api/models
Expect
200 array with feature schema and active flags.
Failure
Without the cookie expect 401.

GET/api/models/PASTE_MODEL_ID_HERE

Inspect artifact manifest and offline metrics.

http://localhost:8000/api/models/PASTE_MODEL_ID_HERE
Expect
200 full metadata.
Failure
Unknown ID returns 404.

POST/api/models/PASTE_MODEL_ID_HERE/activate

Make this the only active model.

http://localhost:8000/api/models/PASTE_MODEL_ID_HERE/activate
Body
None
Expect
200 with active:true.
Check
List models and verify exactly one active item.
Failure
Activate an unknown ID and expect 404.
