Private review and applications

Jobs and rankings are shared. Every response below resolves state, annotations, applications, events and milestones only for the signed-in group member.

Best isolation test: sign in as member A, view and apply to one job, then sign in as member B in another browser profile. Member B must see the same job and rank, but NEW, NOT_STARTED, no notes and an empty timeline.

GET/api/jobs

Search the shared catalog with private workflow filters.

http://localhost:8000/api/jobs?search=Backend&batchId=PASTE_BATCH_ID_HERE&relevanceLabel=STRONG_APPLY&reviewStatus=NEW&applicationStatus=NOT_STARTED&annotation=incomplete&sort=score&page=1&pageSize=50
Enums
Review: NEW, VIEWED, SAVED, DISMISSED. Application: NOT_STARTED, PREPARING, APPLIED, SCREENING, ASSESSMENT, INTERVIEW, OFFER, ACCEPTED, REJECTED, WITHDRAWN. Annotation: all, complete, incomplete. Sort: recent, score.
Expect
200 with items, page, pageSize and total. Each item contains this member's state plus the latest successful shared prediction.
Failure
Invalid enum or pageSize above 100 returns 422.

GET/api/jobs/PASTE_JOB_ID_HERE

Combine shared job/ranking evidence with the current member's private activity.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE
Expect
200 with job, batch, state, annotation, application, milestones, predictions and events.
Copy
Keep application.updatedAt for optimistic planning updates and a milestone ID for later editing.
Failure
Unknown ID returns 404.

POST/api/jobs/PASTE_JOB_ID_HERE/view

Idempotently record that the current member opened the job.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/view
Body
No JSON body.
Expect
200, reviewStatus VIEWED and viewedAt set. Repeating the call preserves the original timestamp and does not overwrite SAVED or DISMISSED.
Failure
Unknown job returns 404.

PATCH/api/jobs/PASTE_JOB_ID_HERE/state

Update only this member's review state and notes.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/state
{
  "relevanceLabel": "STRONG_APPLY",
  "reviewStatus": "SAVED",
  "notes": "Use the backend-focused resume."
}
Expect
200; applicationStatus is computed from this member's separate Application row.
Failure
Empty JSON or null reviewStatus returns 422.

GET/api/jobs/PASTE_JOB_ID_HERE/application

Read this member's application plan.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application
Expect
200. When no row exists, it serializes as NOT_STARTED with null planning fields.
Failure
Unknown job returns 404.

PATCH/api/jobs/PASTE_JOB_ID_HERE/application

Edit planning fields without silently changing the funnel stage.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application
{
  "targetApplyBy": "2026-08-02T18:00:00Z",
  "nextAction": "Tailor backend resume",
  "nextActionDueAt": "2026-08-01T12:00:00Z",
  "portalUrl": "https://company.example/jobs/123",
  "referenceCode": "APP-123",
  "notes": "Emphasize FastAPI and PostgreSQL.",
  "expectedUpdatedAt": "PASTE_CURRENT_UPDATED_AT_HERE"
}
Expect
200 with a new updatedAt.
Failure
A due date without nextAction returns 422; a stale expectedUpdatedAt returns 409.

GET/api/applications

List only the signed-in member's application board.

http://localhost:8000/api/applications?search=Backend&applicationStatus=APPLIED&due=week&sort=nextAction&page=1&pageSize=50
Filters
due: all, overdue, today, week, none. sort: updated, nextAction.
Default
Without applicationStatus, NOT_STARTED jobs are excluded.
Expect
200 with items, statusCounts and overdueCount.

GET/api/applications/summary

Power the current member's dashboard reminders.

http://localhost:8000/api/applications/summary
Expect
200 with statusCounts, overdueCount, dueTodayCount and at most five nearestActions.
Isolation
Another member's due actions must never appear.

POST/api/jobs/PASTE_JOB_ID_HERE/application-events

Atomically change this member's status and append immutable history.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application-events
{
  "applicationStatus": "APPLIED",
  "eventAt": "2026-08-01T10:00:00Z",
  "notes": "Applied through the company portal."
}
Expect
201; omit eventAt for current UTC. First APPLIED sets appliedAt. Terminal stages set closedAt; reopening clears it.
Correction
Any transition, including NOT_STARTED, is allowed.
Failure
Invalid status returns 422.

GET/api/jobs/PASTE_JOB_ID_HERE/application-events

Read only this member's history, newest first.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application-events
Expect
200 array. Add APPLIED, INTERVIEW, then NOT_STARTED and confirm all three remain.
Isolation
A second member receives an empty array until they create their own event.

POST/api/jobs/PASTE_JOB_ID_HERE/application-milestones

Add a private company-specific round without changing the main stage.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application-milestones
{
  "type": "INTERVIEW",
  "title": "Technical Round 2",
  "scheduledAt": "2026-08-07T10:00:00Z",
  "notes": "Prepare system-design examples."
}
Types
SCREENING, ASSESSMENT, INTERVIEW, FOLLOW_UP, OTHER.
Expect
201; copy the milestone ID.
Failure
Blank title returns 422.

PATCH/api/jobs/PASTE_JOB_ID_HERE/application-milestones/PASTE_MILESTONE_ID_HERE

Edit, complete, reopen or cancel a private milestone.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/application-milestones/PASTE_MILESTONE_ID_HERE
{ "status": "COMPLETED", "notes": "Round completed." }
Statuses
PLANNED, COMPLETED, CANCELLED. Completing sets completedAt; reopening clears it.
Expect
200 and no automatic main-stage change.
Isolation
Using another member's milestone ID returns 404.
