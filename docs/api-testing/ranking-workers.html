Ranking and worker control

First test manual result submission. Use a separate normalized batch for worker leasing so the two workflows do not compete.

POST/api/batches/PASTE_BATCH_ID_HERE/rank

Queue ranking pinned to the active profile, model and feature schema.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/rank
Auth
User cookie
Needs
Normalized batch, complete prepared rows, active profile and active model.
Expect
202, status RANK_PENDING, processingRunId and pendingExecution true. Copy the run ID.
Failure
Wrong workflow state or schema mismatch returns 409.

POST/api/batches/PASTE_BATCH_ID_HERE/rankings

Manually provide real results without running a worker.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/rankings
{
  "profileVersionId": "PASTE_PROFILE_ID_HERE",
  "modelVersionId": "PASTE_MODEL_ID_HERE",
  "rankings": [{
    "jobId": "PASTE_JOB_ID_HERE",
    "rank": 1,
    "jediPreferenceScore": 92.5,
    "applyPreferenceProbability": 0.94,
    "componentScores": {
      "roleTitleFit": 5,
      "skillsFit": 5,
      "experienceFit": 4
    }
  }]
}
Rules
Maximum 25; unique batch jobs; ranks contiguous from 1; score 0–100; probability 0–1.
Expect
200, status RANKED and rankingCount.
Failure
Wrong profile/model, foreign job or rank gap returns 409/422.

GET/api/batches/PASTE_BATCH_ID_HERE/rankings

Read the latest successful run, or isolate a historical run.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/rankings?runId=PASTE_RUN_ID_HERE
Auth
User cookie
Expect
200, ordered results with processingRunId.
Failure
Unknown or unsuccessful runId returns 404. Omit runId for latest.

GET/api/batches/PASTE_BATCH_ID_HERE/processing-runs

Inspect normalization/ranking attempts and safe errors.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/processing-runs
Auth
User cookie
Expect
200 newest-first history with version pins and no lease token.
Failure
Unknown batch returns 404.
Worker headers: every route below needs X-JEDI-SERVICE-TOKEN: YOUR_ML_SERVICE_SECRET. Heartbeat, failure and callback also need X-JEDI-LEASE-TOKEN: PASTE_LEASE_TOKEN_HERE.

POST/internal/processing-runs/claim

Claim the oldest queued run for five minutes.

http://localhost:8000/internal/processing-runs/claim
Body
None
Expect
200 with runId, batchId, pinned versions, leaseToken and prepared jobs; 204 if empty.
Failure
User cookie alone or a wrong service token returns 401.

POST/internal/processing-runs/PASTE_RUN_ID_HERE/heartbeat

Extend the active worker lease by five minutes.

http://localhost:8000/internal/processing-runs/PASTE_RUN_ID_HERE/heartbeat
Body
None
Expect
200 with a later leaseExpiresAt.
Failure
Wrong, absent or expired lease token returns 409.

POST/internal/processing-runs/PASTE_RUN_ID_HERE/fail

Preserve a safe worker failure and return the batch to NORMALIZED.

http://localhost:8000/internal/processing-runs/PASTE_RUN_ID_HERE/fail
{
  "errorCode": "MODEL_LOAD_FAILED",
  "errorMessage": "The model bundle could not be loaded."
}
Expect
200, run FAILED and batch NORMALIZED.
Retry
Call the user rank endpoint again to create a fresh queued run.
Failure
Lowercase/short error code gives 422; bad lease gives 409.

POST/internal/batches/PASTE_BATCH_ID_HERE/rankings

Complete the leased run with the same ranking JSON shown above.

http://localhost:8000/internal/batches/PASTE_BATCH_ID_HERE/rankings
{
  "profileVersionId": "PASTE_PROFILE_ID_HERE",
  "modelVersionId": "PASTE_MODEL_ID_HERE",
  "rankings": [{
    "jobId": "PASTE_JOB_ID_HERE",
    "rank": 1,
    "jediPreferenceScore": 93,
    "applyPreferenceProbability": 0.96,
    "componentScores": {"skillsFit": 5}
  }]
}
Expect
200, RANKED. Re-send the identical callback and expect the same result.
Failure
Pinned-version mismatch or invalid lease returns 409.
Caveat
After three expired claims the run is failed with RETRY_EXHAUSTED.
