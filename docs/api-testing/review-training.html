Normalize, annotate and train

Normalize first with the active profile. A training-eligible job needs a prepared row, binary apply label and all nine fit scores.

POST/api/batches/PASTE_BATCH_ID_HERE/normalize

Generate versioned PreparedJobV1 rows for the active profile.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/normalize
Body
None
Needs
Active profile; batch READY, FAILED, NORMALIZED or RANKED.
Expect
200; status NORMALIZED, preparedCount, profileVersionId and featureSchemaVersion.
Failure
No active profile returns 409. Repeating a successful normalization returns replayed:true.

PATCH/api/jobs/PASTE_JOB_ID_HERE/annotation

Save any non-empty subset of manual labels for one job.

http://localhost:8000/api/jobs/PASTE_JOB_ID_HERE/annotation
{
  "relevanceLabel": "STRONG_APPLY",
  "applyLabel": true,
  "roleTitleFit": 5,
  "roleFamilyFit": 4,
  "seniorityFit": 4,
  "locationFit": 5,
  "workModeFit": 5,
  "experienceFit": 4,
  "skillsFit": 5,
  "salaryFit": 6,
  "overallPreference": 5
}
Ranges
All scores 0–5 except salaryFit 0–8.
Expect
200, applyLabel and complete:true.
Failure
Empty JSON or out-of-range score returns 422.

PATCH/api/batches/PASTE_BATCH_ID_HERE/annotations

Save several job annotations atomically for one batch.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/annotations
{
  "annotations": [{
    "jobId": "PASTE_JOB_ID_HERE",
    "relevanceLabel": "DREAM",
    "applyLabel": true,
    "roleTitleFit": 5,
    "roleFamilyFit": 5,
    "seniorityFit": 4,
    "locationFit": 5,
    "workModeFit": 5,
    "experienceFit": 4,
    "skillsFit": 5,
    "salaryFit": 7,
    "overallPreference": 5
  }]
}
Expect
200 array of annotation summaries.
Failure
Repeat the same jobId in one body or use a job from another batch: 422 or 404.

POST/api/batches/PASTE_BATCH_ID_HERE/training-examples

Owner-only promotion of the owner's complete labels into the shared training dataset.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE/training-examples
{ "selection": "ALL_ANNOTATED" }
Choices
ALL_ANNOTATED, YES_ONLY or NO_ONLY.
Expect
200 with addedOrUpdatedCount and annotator provenance stored server-side.
Failure
A non-owner receives 403 GROUP_OWNER_REQUIRED. Incomplete annotations are skipped; invalid selection returns 422.

GET/api/training-examples/export.csv

Download the current training table as CSV.

http://localhost:8000/api/training-examples/export.csv
Expect
200 text/csv; save as jedi-training-examples.csv.
Check
Header includes job_id, batch_id, profile_version_id, feature_schema_version and payload_hash.
Failure
Without authentication expect 401.

POST/api/misc/training-data/import-csv

Owner-only CSV bootstrap or append into shared jobs and training rows.

http://localhost:8000/api/misc/training-data/import-csv
Body
Choose Body → form-data in Postman. Add key file, change its type to File, and select a UTF-8 .csv.
Expect
201 with batchId, importedCount, duplicateCount, trainingExampleCount and row warnings.
Failure
Non-owner returns 403; wrong extension or an empty CSV returns 422.

GET/api/misc/batches/PASTE_BATCH_ID_HERE/annotation-editor

Load this member's editable annotation grid plus shared prepared/training indicators.

http://localhost:8000/api/misc/batches/PASTE_BATCH_ID_HERE/annotation-editor
Expect
200 with batch, rows and completeness counts.
Isolation
Member A and member B receive independent label values for the same rows.
Failure
Unknown batch returns 404.
