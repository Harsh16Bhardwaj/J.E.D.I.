Batch ingestion and deduplication

All routes require the user cookie. Use a new externalBatchId when changing content; identical content is an idempotent replay.

Expect
201; receivedCount 3, validCount 2, duplicateCount 1, jobCount 1, plus one validation report. Copy batchId.
Replay
Send the exact body again: same batch ID and replayed:true.
Failure
Reuse externalBatchId with changed content: 409. If no valid unique job remains: 422 and nothing is created.
Caveat
No app-level size limit; hosted Vercel requests still have a platform payload limit.

GET/api/batches

List batches whose rankedAt is still null.

http://localhost:8000/api/batches?page=1&pageSize=50
Expect
200 with items, page, pageSize and total.
Failure
Use page 0 or pageSize 101 and expect 422.

GET/api/batches/all

List every batch, including ranked batches.

http://localhost:8000/api/batches/all?page=1&pageSize=50
Expect
200 page envelope.
Check
After ranking, compare this result with the unranked list.
Failure
Remove the login cookie and expect 401.

GET/api/batches/PASTE_BATCH_ID_HERE

Read batch metadata, server-calculated action permissions and matching jobs.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE?annotation=all&relevanceLabel=STRONG_APPLY&search=Backend
Filters
annotation: all, unannotated, complete, yes or no. Relevance label and search are optional.
Expect
200; copy the first job ID. Initially omit relevanceLabel so the unannotated job is visible.
Failure
Unknown batch ID returns 404; invalid filter enum returns 422.

DELETE/api/batches/PASTE_BATCH_ID_HERE

Delete only a disposable batch with no annotations, training rows or rankings.

http://localhost:8000/api/batches/PASTE_BATCH_ID_HERE
Expect
204 and no body.
Failure
Delete the main batch after annotation or ranking and expect 409.
Advice
Create a separate one-job batch specifically for the success test.
