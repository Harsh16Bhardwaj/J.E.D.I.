Service and authentication

Prove the process, database and private login work before creating product data.

GET/

Read service metadata.

Auth
None
Request
http://localhost:8000/
Expect
200; service, version, docsUrl and status.
Failure
Connection refused means the API server is not running.

GET/health/live

Checks only that Python is alive.

http://localhost:8000/health/live
Auth
None
Expect
200 with {"service":"jedi-ml","status":"ok"}.
Failure
Stop the API process and confirm the request cannot connect.
Caveat
This does not prove the database works.

GET/health/ready

Checks database access and migration readiness.

http://localhost:8000/health/ready
Auth
None
Expect
200 and status ready.
Failure
503 SERVICE_UNAVAILABLE means DB access or the latest required migration is unavailable.

GET/v1/info

Lists the API version and advertised capabilities.

http://localhost:8000/v1/info
Auth
None
Expect
200 with service, apiVersion and capabilities.
Failure
A missing route indicates the wrong server or an outdated deployment.

POST/api/auth/register

Creates a group member using the reusable five-character invitation code.

http://localhost:8000/api/auth/register
{
  "inviteCode": "PASTE_5_CHARACTER_CODE",
  "email": "friend@example.com",
  "password": "StrongPassword123!"
}
Auth
None
Expect
201, a session cookie, group summary and onboardingComplete: false.
Copy
The browser stores the cookie automatically; continue with GET /api/onboarding.
Failure
Try an invalid, expired or revoked code and expect INVITE_INVALID, INVITE_EXPIRED or INVITE_REVOKED.

POST/api/auth/login

Matches the database email and Argon2 password, then sets the session cookie.

http://localhost:8000/api/auth/login
{
  "email": "YOUR_BOOTSTRAPPED_EMAIL",
  "password": "YOUR_BOOTSTRAPPED_PASSWORD"
}
Headers
Content-Type: application/json
Expect
200, user ID/email, group, onboarding state, and a jedi_session cookie.
Failure
Use a wrong password and expect 401 AUTH_REQUIRED.

GET/api/auth/session

Confirms Postman is sending the stored login cookie.

http://localhost:8000/api/auth/session
Auth
User cookie
Expect
200 with the same user ID and email.
Failure
Delete the cookie and expect 401 AUTH_REQUIRED.

POST/api/auth/logout

Deletes the session cookie.

http://localhost:8000/api/auth/logout
Body
None
Expect
204 with no response body.
Failure test
Call session afterward and expect 401; log in again before continuing.

POST/api/invitations

Generates the group's reusable invitation code and revokes its previous active code.

http://localhost:8000/api/invitations
Auth
Group owner cookie
Body
None
Expect
201; copy the five-character code immediately because it is returned only once.
Failure
A member account receives 403 GROUP_OWNER_REQUIRED.

GET/api/invitations

Lists safe invitation metadata without revealing any invitation code.

http://localhost:8000/api/invitations
Auth
Group owner cookie
Expect
200; inspect expiry, revocation and usage count.
Failure
A member account receives 403.

DELETE/api/invitations/PASTE_INVITATION_ID_HERE

Revokes one invitation without affecting registered members.

http://localhost:8000/api/invitations/PASTE_INVITATION_ID_HERE
Auth
Group owner cookie
Expect
204.
Failure
An unknown ID returns 404.

GET/api/onboarding

Returns shared model/profile context, saved member profile and suggested tags.

http://localhost:8000/api/onboarding
Auth
Member cookie
Expect
200 with rankingMode: SHARED_GROUP_PROFILE.
Failure
An account without group membership receives 409 GROUP_MEMBERSHIP_REQUIRED.

POST/api/onboarding

Saves a member profile for v2, completes onboarding and adds the account email to the newsletter.

http://localhost:8000/api/onboarding
{
  "resumeText": "Python backend engineer with FastAPI experience.",
  "preferredTitles": ["Backend Engineer", "ML Engineer"],
  "preferredLocations": ["Remote", "Bengaluru"],
  "preferredSkills": ["Python", "FastAPI", "PostgreSQL"],
  "experienceMinYears": 0,
  "experienceMaxYears": 2,
  "salaryMin": 800000,
  "salaryMax": 4000000,
  "salaryCurrency": "INR"
}
Auth
Member cookie
Expect
200, onboardingComplete: true and the saved member profile.
Failure
Reverse a minimum and maximum to receive 422 VALIDATION_ERROR.
Caveat
The member profile is saved for v2; v1 rankings continue to use the shared group profile.

GET/api/group

Returns the shared group, directory, active profile and active model.

http://localhost:8000/api/group
Auth
Member cookie
Expect
200 with member count and isGroupOwner.
Failure
Without authentication expect 401.

Standard error shape

{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Request validation failed.",
    "requestId": "request-correlation-id",
    "details": []
  }
}

Keep the requestId when investigating failures. Private responses also carry Cache-Control: no-store.
